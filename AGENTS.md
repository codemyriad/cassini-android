# Working in this repository

- Commit and push completed, reviewable milestones to `origin` when appropriate, as requested by the user. The remote is `git@github.com:codemyriad/cassini-android`.
- Clone with `--recurse-submodules` (or run `git submodule update --init`): the pinned conformance vectors come from the `third_party/cassini-format` submodule, and the JVM tests fail without them. Use `./scripts/setup.sh` to fetch the pinned Android runtime. Run Gradle with JDK 17. Build with `./gradlew :app:assembleDebug`; verify relevant changes with `./gradlew detekt :app:testDebugUnitTest :app:lintDebug`, as CI does.
- Device checks use `scripts/device-smoke.sh`. Its direct adb instrumentation retains app data; Gradle's managed connected-test cleanup can uninstall the app and erase downloaded models.
- Keep model weights, AAR downloads, recordings, YouTube-derived and private test audio, build outputs and device-specific SDK paths out of commits. Their local paths are ignored. Two test inputs are committed on purpose (`fixtures/README.md`): the CC-BY-4.0 FLEURS clip in `fixtures/audio/` and the captured `fixtures/filesdir/` trees, which hold synthetic voiceprints and model stand-ins. A new tree stays ignored until it is reviewed and named in `.gitignore`.
- Public format references are pinned in the `third_party/cassini-format` submodule; a sibling `../cassini-format` checkout is optional, for newer revisions (`-PcassiniConformanceDir`); the desktop transcription pipeline and web viewer live in `../gocassini`. Document any differences from the desktop runtime and distinguish a word-body JSON export from a complete portable Opus artifact.
