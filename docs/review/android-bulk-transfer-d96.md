# Android bulk transfer (D96)

The Library picker uses OpenMultipleDocuments and accepts audio, Ogg and ZIP. A batch runs on the app scope's IO dispatcher, so leaving the Library does not abort it. Cancel closes blocked provider streams and stops copying at the next cancellation check. The Library reports imported files, digest duplicates, ignored archive entries and failures.

ZIP import streams local entries; it does not extract paths or recurse into nested ZIPs. Names containing absolute paths, parent/current-directory components, backslashes, drive separators or NUL are rejected. Each archive is limited to 1,000 entries, 4 GiB plus a 16 MiB header allowance of consumed input, and 4 GiB of actual expanded bytes. Ignored entries count toward both entry and expanded-byte limits. Advertised sizes are checked but never trusted instead of the actual counters. An unsafe or broken archive stops; earlier successful imports remain and count in the summary.

A supported entry is staged under a random private file name. Its original display name is passed separately to ImportRepository.import, which uses the existing copy/hash, content classification, deduplication and catalogue insertion path. Unsupported files and nested archives are ignored. Imported data never uses an archive path as a filesystem path. Each staging file is deleted after its import; the batch directory is deleted before completion is published. A process restart clears interrupted staging before the next transfer.

Export notes as ZIP opens an explicit selector, with all eligible notes initially selected. Unchecking notes exports only the remaining selection. A recording in progress is excluded. Cassini documents keep their complete .opus contents; **per Silvio's clarification, plain audio keeps its original format**, as in the existing individual export. File names use ExportNames.file, with numeric suffixes for case-insensitive collisions. There is no manifest, model, catalogue or voiceprint file in the ZIP.

Title synchronization uses the existing repository behavior. Each note is copied under its writer lock to a private immutable snapshot. CRC and size are calculated from that snapshot, then each ZIP entry is written with STORED (no compression). The exporter also limits a batch to 1,000 notes and 4 GiB; it keeps a 128 MiB free-space margin while staging. The complete ZIP is staged before writing to the selected destination, so cancellation during preparation cannot produce an apparently complete destination. A failed destination write attempts to delete the incomplete document; a provider can refuse that deletion. Private staging is removed in either case.

All heavy work stays off the main thread. Completion is published only after streams and private staging are closed/removed. The process-scoped operation does not promise resumption after process death. Completed imports remain valid when a later file fails or the user cancels.

Task A ownership is preserved: DocumentRepository.kt, CassiniDocument.kt, the format pin and meeting-time semantics are unchanged. AppGraph adds only the transfer binding. The import/export flow and its tests own the remaining changes. The following Files-provider task is a separate PR.
