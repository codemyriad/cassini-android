Changes from the original model:
- Cassini exported the model to ONNX and quantized it to INT8 with the
  sherpa-onnx export script scripts/nemo/nemotron-3-diarization/export_onnx.py
  (from k2-fsa/sherpa-onnx#4006).
- Cassini compressed the exported file with seekable Zstandard. The
  decompressed contents are the exported file, byte for byte.
ONNX conversion and INT8 quantization are changes from the original model
format of NVIDIA. provenance.json gives the toolchain, the sizes and the
SHA-256 hashes.
